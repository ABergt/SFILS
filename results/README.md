# Findings

Dataset Summary

    The database contains 437,115 library usage records with 70,412,694 total checkouts and 33,101,214 renewals. The average checkout total per record is 161.09 and the average renewal total is 75.73.

    Adults account for the majority of the records (271,588) and the highest total checkout volume (34,150,818). Senior patrons have the second-highest checkout volume (18,593,574) followed by Teen patrons (9,484,428).

    Retired Staff and Staff have the highest average checkout totals per record (1,355.66 and 1,204.92).
